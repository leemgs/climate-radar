# Artifacts

Outputs of the reference implementation in [`../code/`](../code/), plus project assets. Everything in `results/` and `audit/sample_log.jsonl` is regenerated by `make reproduce` (run in `code/`).

| Path | Content | Generated? |
|---|---|---|
| `results/metrics.json` | AER, ECE, and equal-opportunity differences (elderly, migrant) on synthetic data | yes |
| `results/fitted.csv` | Fitted composite risk with uncertainty per record | yes |
| `results/fig_risk_hist.png`, `results/fig_calibration.png` | Risk histogram and calibration plot | yes |
| `audit/sample_log.jsonl` | Accountability log of emitted recommendations | yes |
| `audit/audit_log_schema.json` | JSON schema of the audit log | no |
| `model_cards/model_card.md` | Model card of the reference risk model | no |
| `climate-radar-logo.png` | Project logo | no |

These results come from **synthetic data** and are not the user-study results reported in the papers in [`../paper/`](../paper/).
