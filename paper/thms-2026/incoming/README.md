# ACHDF Study Supporting Materials
## Supplementary Evidence for Reproducibility

This folder contains the original supporting materials corresponding to the documented experimental procedures in the revised paper.

### Contents

1. **Fig_S1_Baseline.png**, **Fig_S2_Recommend.png**, **Fig_S3_Escalate.png**  
   Original screenshots of the study interfaces (captured during pilot testing with scenario S03 values).

2. **scenario_config_and_design.xlsx**  
   - Global thresholds (τu, τc)  
   - Per-scenario parameters (r, u, c, escalation flag)  
   - Reference actions and AI recommendations  
   - AI correctness labels (for automation-bias analysis)

3. **expert_consensus_reference_actions.xlsx**  
   Expert ratings and consensus process for determining reference actions.

4. **training_checklist_and_records.xlsx**  
   Training protocol checklist + anonymized completion records for all 52 participants.

5. **ai_recommendation_generation_log.csv**  
   Full trial-level log of AI recommendations and their correctness (enables automation bias analysis).

6. **automation_bias_analysis_summary.md**  
   Preliminary analysis made possible by the recommendation correctness labels.

All materials are consistent with the reported results (AER 0.62 / 0.81, escalation rate 28.8%, etc.).
